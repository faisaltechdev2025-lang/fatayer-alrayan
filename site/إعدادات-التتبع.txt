إعدادات أدوات التتبع لموقع فطيرة الريان
=======================================

كل الإعدادات في ملف واحد: tracking.js (أعلى الملف، داخل CFG).
اترك أي معرّف فارغاً فلا يُحمَّل شيء من تلك الأداة.

1) أين أجد المعرّفات؟
- Google Analytics 4: analytics.google.com > Admin > Data streams > Web > "Measurement ID" (يبدأ بـ G-)
- TikTok Pixel: TikTok Ads Manager > Assets > Events > Web Events > Pixel ID
- Snapchat Pixel: Snapchat Ads Manager > Events Manager > Pixel ID
ثم الصقها في tracking.js:
    ga4: 'G-XXXXXXXXXX',  tiktok: '...',  snap: '...'

2) ماذا يُتتبع؟
- زيارة الصفحة (تلقائياً)
- اختيار الفرع
- إضافة صنف للسلة (add_to_cart / AddToCart / ADD_CART)
- فتح صفحة تأكيد الطلب (begin_checkout / InitiateCheckout / START_CHECKOUT)
- إرسال طلب كاش عبر واتساب (generate_lead / PlaceAnOrder / PURCHASE)
- دفع إلكتروني مؤكد (purchase / CompletePayment / PURCHASE) — لا يُرسل في الوضع التجريبي
- الضغط على واتساب أو الاتصال (contact / Contact)
لا تُرسل أي بيانات شخصية (الاسم، الرقم، العنوان، الموقع)، فقط الأصناف والقيمة والفرع.

3) السرعة
- لا يُحمَّل أي سكربت تتبع مع عرض الصفحة. يُحمَّل بعد اكتمال الصفحة أثناء الخمول أو عند أول لمس/تمرير.
- الأحداث التي تحصل قبل التحميل تُحفظ وتُرسل تلقائياً.

4) الموافقة (اختياري)
- غيّر requireConsent إلى true ليظهر شريط موافقة، ولا يُحمَّل التتبع إلا بعد "موافق".
- الأفضل تفعيله إن كنت تستهدف جمهوراً يتطلب ذلك، ويُنصح بإضافة سياسة خصوصية.

5) كيف أتأكد أنه يعمل؟
- GA4: Admin > DebugView، أو التقارير الفورية (Realtime).
- TikTok: إضافة TikTok Pixel Helper، أو Test Events في مدير الأحداث.
- Snapchat: إضافة Snap Pixel Helper، أو Test Events في Events Manager.
- جرّب على الموقع المرفوع (Netlify) وليس من الملف المحلي.

6) ملاحظة عن الأحداث
- طلبات الكاش المرسلة عبر واتساب تُحتسب "طلباً مُرسلاً" وليست دفعاً مؤكداً.
- لا تُحتسب أحداث وضع الدفع التجريبي (demo) كمبيعات.
